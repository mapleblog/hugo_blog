# IT Manager 🤵

- IT Manager ≠ **技术最强的人**
- IT Manager = **用技术解决业务问题的人，注重业务持续化运作** 

| Roles               | Mindset                                   |
| ------------------- | ----------------------------------------- |
| IT Manager          | Proactive Strategic Thinking 主动战略思维 |
| IT Support Engineer | Reactive 被动响应                         |
|                     |                                           |



- **核心能力是以业务角度为考量**：

  - 设计一套企业 IT 蓝图

    - 了解各部门业务流程 + 部门之间协作关系 + 支撑企业未来的**商业模式** = 业务流程的数字化支撑

    - 企业IT基础架构 + 网络安全策略 + 服务器 + 备份策略 + 网络 = 技术架构的超前布局

    - **数据驱动** 和 **标准化** = 数据资产的变现能力
    - 标准化 = 不管谁来做，做出来的东西都一样
      
    - 数据驱动 = 别听“谁”说的，看“数”据展示的
    
  - 让系统稳定
  - 让风险可控
  - 让成本合理 
  - 让项目成功
  - 让团队成长

  **而不是**：

  - 写最多代码
  - 配最多服务器

- 没有技术底盘， 战略是空谈

- IT Manager失败的常见原因：

  - 过度技术化
  - 不会汇报
  - 不懂风险等级
  - 不会说“No”
  - 不会控制Scope

  管理不是技术问题， 是决策问题。



# 🧱 1️⃣ IT Infrastructure（地基）

- Server（On-prem / Cloud）
- Network
- Backup
- Disaster Recovery
- Identity Management
- Endpoint Management
  - 
- Monitoring

### 核心你要掌握的不是配置，而是：

- 架构逻辑
- 高可用设计
- 单点故障分析
- 容量规划
- 成本控制



# 🔐 2️⃣ Cyber Security（防火墙）

核心你必须懂：

- Risk Assessment
- Access Control
- Zero Trust 概念
- Phishing / Social Engineering
- Ransomware 防御
- Backup 3-2-1 原则
- Security Policy 制定

### 重点

你不需要成为Security Engineer
 但你必须懂：

- 攻击路径
- 风险等级
- 商业影响



# 🧠 3️⃣ IT Strategy（战略）

必须学会：

- IT Alignment with Business
- 预算规划
- Vendor 管理
- TCO 分析
- 技术选型决策
- Build vs Buy 判断

举例：

> 不是“我们可以做”
>  而是“做这件事对公司有没有ROI”





# 🚀 4️⃣ IT Project & Management（落地能力）

如果没有这个，你前面全部都没用。

必须掌握：

- 项目生命周期
- Scope 管控
- 风险管理
- Stakeholder 管理
- Change Management
- SOP 制定
- Incident Response 流程



CIO - Focus on IT Strategy / Infrastructure
CTO - Focus on technology products / services for customers
CISO - Focus on data protection and cyber security
CDO - Focus on drives digital transformation
CDO - Focus on manages data strategy and analytics
CPO - Focus on oversees data privacy policies



**Configuration Drift** 配置漂移
**Stakeholder Management**（利益相关者管理）
意思是：你需要了解老板的决策逻辑，然后用他在乎的语言来说服他。
**Risk Acceptance Documentation**（风险接受文件）
