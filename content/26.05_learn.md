## Ventoy

1. 下载 **Ventoy**  https://www.ventoy.net/en/download.html
2. Unzip 文档然后执行目录中的 **Ventoy2Disk.exe**
3. 将U盘格式化后，可以将多个系统ISO镜像拷贝到U盘
4. Secure Boot 会影响 Ventoy 需要禁用 Secure Boot 或者将 Deploy Mode 改为 Audit Mode，完成系统安装后再修改回原本配置





## Bash Command

#### alias 

当前用户每次需要执行长命令的时候，可以创建别名（alias）。
```bash
alias update='sudo apt update && sudo apt upgrade -y'
```

创建好别名后，需要刷新终端配置
```bash
source ~/.bashrc
```

可以在当前用户下开始使用别名 `update` 命令

---

如果需要应用到全局用户，需要在全局配置文件创建别名：
```bash
# 打开全局终端配置文件
sudo vim /etc/bash.bashrc

# 创建新别名指令
alias update='sudo apt update && sudo apt upgrade -y'
```

添加好别名后，需要刷新全局终端配置
```bash
source /etc/bash.bashrc
```

可以开始在全用户使用别名 `update` 命令

####  `<<EOL ... EOL`

```bash
创建新的文件
cat <<EOL > your_file
这里是你想写入的内容
可以有很多行
哪怕有空格和换行也没关系
EOL

追加内容到文件
cat <<EOL >> your_file
Hello, Linux...
EOL
```
